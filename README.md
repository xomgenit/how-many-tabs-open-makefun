## The entry

**173**

One number, digits only: my honest count of open browser tabs. A specific,
odd, three-digit count — far above the typical 10–30 tabs, yet entirely
believable for a researcher with docs, dashboards and repos open. It reads as
a real counted number, not a round guess, and hints at a life of deep
research.

## How it works

`main.ts` writes the number `173` (no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`).

```sh
MAKEFUN_OUTPUT_DIR=out npx tsx main.ts
cat out/entry.txt  # 173
```
